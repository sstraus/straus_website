# Audio credits

Every file here is CC0 1.0 (public domain dedication,
<https://creativecommons.org/publicdomain/zero/1.0/>). No attribution is required; we credit
the authors anyway. Licences checked on the source pages on 2026-09-27.

Formats: `.ogg` is Opus (music 96 kbps stereo, effects 48 kbps mono), `.mp3` is the fallback
(music 128 kbps, effects 96 kbps mono). Loops were re-cut with a crossfaded seam (ffmpeg).

## Synthesized in the page

No file. Built with the Web Audio API at run time: the player's engine in `engine-sound.js`
(turbine whine, blade air, sub and rumble, field hum, air rush), and in `audio.js` the boost
whoosh, the AI pass-by whoosh and the mine crackle.
